Abstract base class for key listeners. Provides a basic foundation for entering and editing text. Subclasses should override [onKeyDown](https://developer.android.com/reference/kotlin/android/text/method/BaseKeyListener#onKeyDown(android.view.View,%20android.text.Editable,%20kotlin.Int,%20android.view.KeyEvent))and #onKeyUp to insert characters as keys are pressed.

<br />

As for all implementations of [KeyListener](https://developer.android.com/reference/kotlin/android/text/method/KeyListener), this class is only concerned with hardware keyboards. Software input methods have no obligation to trigger the methods in this class.

### backspace

Added in [API level 1](https://developer.android.com/guide/topics/manifest/uses-sdk-element.html#ApiLevels) 

```
open fun backspace(
    view: View!, 
    content: Editable!, 
    keyCode: Int, 
    event: KeyEvent!
): Boolean
```

Performs the action that happens when you press the [KeyEvent.KEYCODE_DEL](https://developer.android.com/reference/kotlin/android/view/KeyEvent.html#KEYCODE_DEL:kotlin.Int) key in a [TextView](https://developer.android.com/reference/kotlin/android/widget/TextView.html#). If there is a selection, deletes the selection; otherwise, deletes the character before the cursor, if any; ALT+DEL deletes everything on the line the cursor is on.
