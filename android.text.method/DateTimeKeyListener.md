For entering dates and times in the same text field.

<br />

As for all implementations of [KeyListener](https://developer.android.com/reference/kotlin/android/text/method/KeyListener), this class is only concerned with hardware keyboards. Software input methods have no obligation to trigger the methods in this class.

Added in [API level 1](https://developer.android.com/guide/topics/manifest/uses-sdk-element.html#ApiLevels) 

```
protected open fun getAcceptedChars(): CharArray
```

You can say which characters you can accept.

| Return ||
|-----------------------------------------------------------------------------------------|-----------------------------|
| [CharArray](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin/-char-array/index.html) | This value cannot be`null`. |

## Properties

### CHARACTERS

Added in [API level 1](https://developer.android.com/guide/topics/manifest/uses-sdk-element.html#ApiLevels) 
Deprecated in [API level 26](https://developer.android.com/guide/topics/manifest/uses-sdk-element.html#ApiLevels) 

```
static val CHARACTERS: CharArray!
```

**Deprecated:** *Use [getAcceptedChars()](https://developer.android.com/reference/kotlin/android/text/method/DateTimeKeyListener#getAcceptedChars())instead.*

This field used to list the characters that were used. But is now a fixed data field that is the list of code units used for the deprecated case where the class is instantiated with null or no input parameter.
