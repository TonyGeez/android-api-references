Base class for implementing a policy update receiver. This class provides a convenience for interpreting the raw intent actions ([ACTION_DEVICE_POLICY_SET_RESULT](https://developer.android.com/reference/kotlin/android/app/admin/PolicyUpdateReceiver#ACTION_DEVICE_POLICY_SET_RESULT:kotlin.String) and [ACTION_DEVICE_POLICY_CHANGED](https://developer.android.com/reference/kotlin/android/app/admin/PolicyUpdateReceiver#ACTION_DEVICE_POLICY_CHANGED:kotlin.String)) that are sent by the system.

The callback methods happen on the main thread of the process. Thus, long-running operations must be done on another thread.

When publishing your`PolicyUpdateReceiver`subclass as a receiver, it must require the [android.Manifest.permission#BIND_DEVICE_ADMIN](https://developer.android.com/reference/kotlin/android/Manifest.permission.html#BIND_DEVICE_ADMIN:kotlin.String) permission.

Admins can implement [DeviceAdminService](https://developer.android.com/reference/kotlin/android/app/admin/DeviceAdminService) to ensure they receive all policy updates (for policies they have set) via [onPolicyChanged](https://developer.android.com/reference/kotlin/android/app/admin/PolicyUpdateReceiver#onPolicyChanged(android.content.Context,%20kotlin.String,%20android.os.Bundle,%20android.app.admin.TargetUser,%20android.app.admin.PolicyUpdateResult))by constantly being bound to by the system. For more information see [DeviceAdminService](https://developer.android.com/reference/kotlin/android/app/admin/DeviceAdminService).

### ACTION_DEVICE_POLICY_CHANGED

Added in [API level 34](https://developer.android.com/guide/topics/manifest/uses-sdk-element.html#ApiLevels) 

```
static val ACTION_DEVICE_POLICY_CHANGED: String
```

Action for a broadcast sent to admins to communicate back a change in a policy they have previously set.

Admins wishing to receive these updates should include this action in the intent filter for their receiver in the manifest, the receiver must be protected by [android.Manifest.permission#BIND_DEVICE_ADMIN](https://developer.android.com/reference/kotlin/android/Manifest.permission.html#BIND_DEVICE_ADMIN:kotlin.String) to ensure that only the system can send updates.

Admins shouldn't implement [onReceive](https://developer.android.com/reference/kotlin/android/app/admin/PolicyUpdateReceiver#) and should instead implement [onPolicyChanged](https://developer.android.com/reference/kotlin/android/app/admin/PolicyUpdateReceiver#onPolicyChanged(android.content.Context,%20kotlin.String,%20android.os.Bundle,%20android.app.admin.TargetUser,%20android.app.admin.PolicyUpdateResult)). 

 Value: "android.app.admin.action.DEVICE_POLICY_CHANGED"
