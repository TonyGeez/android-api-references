## Exceptions

| [BufferOverflowException](https://developer.android.com/reference/kotlin/java/nio/BufferOverflowException) | Unchecked exception thrown when a relative*put*operation reaches the target buffer's limit. |
| [BufferUnderflowException](https://developer.android.com/reference/kotlin/java/nio/BufferUnderflowException) | Unchecked exception thrown when a relative*get*operation reaches the source buffer's limit. |
| [InvalidMarkException](https://developer.android.com/reference/kotlin/java/nio/InvalidMarkException) | Unchecked exception thrown when an attempt is made to reset a buffer when its mark is not defined. |
| [ReadOnlyBufferException](https://developer.android.com/reference/kotlin/java/nio/ReadOnlyBufferException) | Unchecked exception thrown when a content-mutation method such as put or compact is invoked upon a read-only buffer. |
