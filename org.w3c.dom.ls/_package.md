# org.w3c.dom.ls

## Interfaces

| [DOMImplementationLS](../org/w3c/dom/ls/DOMImplementationLS.md) | `DOMImplementationLS`contains the factory methods for creating Load and Save objects. |
| --- | --- |
| [LSInput](../org/w3c/dom/ls/LSInput.md) | This interface represents an input source for data. |
| [LSOutput](../org/w3c/dom/ls/LSOutput.md) | This interface represents an output destination for data. |
| [LSParser](../org/w3c/dom/ls/LSParser.md) | An interface to an object that is able to build, or augment, a DOM tree from various input sources. |
| --- | --- |
| [LSParserFilter](../org/w3c/dom/ls/LSParserFilter.md) | `LSParserFilter`s provide applications the ability to examine nodes as they are being constructed while parsing. |
| [LSResourceResolver](../org/w3c/dom/ls/LSResourceResolver.md) | `LSResourceResolver`provides a way for applications to redirect references to external resources. |
| [LSSerializer](../org/w3c/dom/ls/LSSerializer.md) | A`LSSerializer`provides an API for serializing (writing) a DOM document out into XML. |
| --- | --- |
