## Interfaces

| [DOMImplementationLS](https://developer.android.com/reference/kotlin/org/w3c/dom/ls/DOMImplementationLS) | `DOMImplementationLS`contains the factory methods for creating Load and Save objects. |
| --- | --- |
| [LSInput](https://developer.android.com/reference/kotlin/org/w3c/dom/ls/LSInput) | This interface represents an input source for data. |
| [LSOutput](https://developer.android.com/reference/kotlin/org/w3c/dom/ls/LSOutput) | This interface represents an output destination for data. |
| [LSParser](https://developer.android.com/reference/kotlin/org/w3c/dom/ls/LSParser) | An interface to an object that is able to build, or augment, a DOM tree from various input sources. |
| --- | --- |
| [LSParserFilter](https://developer.android.com/reference/kotlin/org/w3c/dom/ls/LSParserFilter) | `LSParserFilter`s provide applications the ability to examine nodes as they are being constructed while parsing. |
| [LSResourceResolver](https://developer.android.com/reference/kotlin/org/w3c/dom/ls/LSResourceResolver) | `LSResourceResolver`provides a way for applications to redirect references to external resources. |
| [LSSerializer](https://developer.android.com/reference/kotlin/org/w3c/dom/ls/LSSerializer) | A`LSSerializer`provides an API for serializing (writing) a DOM document out into XML. |
