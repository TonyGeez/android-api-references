# org.xml.sax.ext

## Interfaces

| [Attributes2](https://developer.android.com/reference/kotlin/org/xml/sax/ext/Attributes2) | SAX2 extension to augment the per-attribute information provided though [Attributes](https://developer.android.com/reference/kotlin/org/xml/sax/Attributes.html#). |
| --- | --- |
| [DeclHandler](https://developer.android.com/reference/kotlin/org/xml/sax/ext/DeclHandler) | SAX2 extension handler for DTD declaration events. |
| [EntityResolver2](https://developer.android.com/reference/kotlin/org/xml/sax/ext/EntityResolver2) | Extended interface for mapping external entity references to input sources, or providing a missing external subset. |
| [LexicalHandler](https://developer.android.com/reference/kotlin/org/xml/sax/ext/LexicalHandler) | SAX2 extension handler for lexical events. |
| --- | --- |
| [Locator2](https://developer.android.com/reference/kotlin/org/xml/sax/ext/Locator2) | SAX2 extension to augment the entity information provided though a [Locator](https://developer.android.com/reference/kotlin/org/xml/sax/Locator.html#). |

## Classes

| [Attributes2Impl](https://developer.android.com/reference/kotlin/org/xml/sax/ext/Attributes2Impl) | SAX2 extension helper for additional Attributes information, implementing the [Attributes2](https://developer.android.com/reference/kotlin/org/xml/sax/ext/Attributes2) interface. |
| --- | --- |
| [DefaultHandler2](https://developer.android.com/reference/kotlin/org/xml/sax/ext/DefaultHandler2) | This class extends the SAX2 base handler class to support the SAX2 [LexicalHandler](https://developer.android.com/reference/kotlin/org/xml/sax/ext/LexicalHandler), [DeclHandler](https://developer.android.com/reference/kotlin/org/xml/sax/ext/DeclHandler), and [EntityResolver2](https://developer.android.com/reference/kotlin/org/xml/sax/ext/EntityResolver2) extensions. |
| [Locator2Impl](https://developer.android.com/reference/kotlin/org/xml/sax/ext/Locator2Impl) | SAX2 extension helper for holding additional Entity information, implementing the [Locator2](https://developer.android.com/reference/kotlin/org/xml/sax/ext/Locator2) interface. |
