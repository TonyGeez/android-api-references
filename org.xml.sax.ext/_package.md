# org.xml.sax.ext

## Interfaces

| [Attributes2](../org/xml/sax/ext/Attributes2.md) | SAX2 extension to augment the per-attribute information provided though [Attributes](../org/xml/sax/Attributes.md). |
| --- | --- |
| [DeclHandler](../org/xml/sax/ext/DeclHandler.md) | SAX2 extension handler for DTD declaration events. |
| [EntityResolver2](../org/xml/sax/ext/EntityResolver2.md) | Extended interface for mapping external entity references to input sources, or providing a missing external subset. |
| [LexicalHandler](../org/xml/sax/ext/LexicalHandler.md) | SAX2 extension handler for lexical events. |
| --- | --- |
| [Locator2](../org/xml/sax/ext/Locator2.md) | SAX2 extension to augment the entity information provided though a [Locator](../org/xml/sax/Locator.md). |

## Classes

| [Attributes2Impl](../org/xml/sax/ext/Attributes2Impl.md) | SAX2 extension helper for additional Attributes information, implementing the [Attributes2](../org/xml/sax/ext/Attributes2.md) interface. |
| --- | --- |
| [DefaultHandler2](../org/xml/sax/ext/DefaultHandler2.md) | This class extends the SAX2 base handler class to support the SAX2 [LexicalHandler](../org/xml/sax/ext/LexicalHandler.md), [DeclHandler](../org/xml/sax/ext/DeclHandler.md), and [EntityResolver2](../org/xml/sax/ext/EntityResolver2.md) extensions. |
| [Locator2Impl](../org/xml/sax/ext/Locator2Impl.md) | SAX2 extension helper for holding additional Entity information, implementing the [Locator2](../org/xml/sax/ext/Locator2.md) interface. |
