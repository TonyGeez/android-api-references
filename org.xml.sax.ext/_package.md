# org.xml.sax.ext

## Interfaces

| [Attributes2](Attributes2.md) | SAX2 extension to augment the per-attribute information provided though [Attributes](../org.xml.sax/Attributes.md). |
| --- | --- |
| [DeclHandler](DeclHandler.md) | SAX2 extension handler for DTD declaration events. |
| [EntityResolver2](EntityResolver2.md) | Extended interface for mapping external entity references to input sources, or providing a missing external subset. |
| [LexicalHandler](LexicalHandler.md) | SAX2 extension handler for lexical events. |
| --- | --- |
| [Locator2](Locator2.md) | SAX2 extension to augment the entity information provided though a [Locator](../org.xml.sax/Locator.md). |

## Classes

| [Attributes2Impl](Attributes2Impl.md) | SAX2 extension helper for additional Attributes information, implementing the [Attributes2](Attributes2.md) interface. |
| --- | --- |
| [DefaultHandler2](DefaultHandler2.md) | This class extends the SAX2 base handler class to support the SAX2 [LexicalHandler](LexicalHandler.md), [DeclHandler](DeclHandler.md), and [EntityResolver2](EntityResolver2.md) extensions. |
| [Locator2Impl](Locator2Impl.md) | SAX2 extension helper for holding additional Entity information, implementing the [Locator2](Locator2.md) interface. |
