# java.security.interfaces

## Interfaces

| [DSAKey](DSAKey.md) | The interface to a DSA public or private key. |
| --- | --- |
| [DSAKeyPairGenerator](DSAKeyPairGenerator.md) | An interface to an object capable of generating DSA key pairs. |
| [DSAParams](DSAParams.md) | Interface to a DSA-specific set of key parameters, which defines a DSA*key family*. |
| [DSAPrivateKey](DSAPrivateKey.md) | The standard interface to a DSA private key. |
| --- | --- |
| [DSAPublicKey](DSAPublicKey.md) | The interface to a DSA public key. |
| [ECKey](ECKey.md) | The interface to an elliptic curve (EC) key. |
| [ECPrivateKey](ECPrivateKey.md) | The interface to an elliptic curve (EC) private key. |
| --- | --- |
| [ECPublicKey](ECPublicKey.md) | The interface to an elliptic curve (EC) public key. |
| [EdECKey](EdECKey.md) | An interface for an elliptic curve public/private key as defined by [RFC 8032: Edwards-Curve Digital Signature Algorithm (EdDSA)](https://tools.ietf.org/html/rfc8032). |
| [EdECPrivateKey](EdECPrivateKey.md) | An interface for an elliptic curve private key as defined by [RFC 8032: Edwards-Curve Digital Signature Algorithm (EdDSA)](https://tools.ietf.org/html/rfc8032). |
| --- | --- |
| [EdECPublicKey](EdECPublicKey.md) | An interface for an elliptic curve public key as defined by [RFC 8032: Edwards-Curve Digital Signature Algorithm (EdDSA)](https://tools.ietf.org/html/rfc8032). |
| [RSAKey](RSAKey.md) | The interface to a public or private key in [PKCS#1 v2.2](https://tools.ietf.org/rfc/rfc8017.txt) standard, such as those for RSA, or RSASSA-PSS algorithms. |
| [RSAMultiPrimePrivateCrtKey](RSAMultiPrimePrivateCrtKey.md) | The interface to an RSA multi-prime private key, as defined in the [PKCS#1 v2.2](https://tools.ietf.org/rfc/rfc8017.txt) standard, using the*Chinese Remainder Theorem*(CRT) information values. |
| --- | --- |
| [RSAPrivateCrtKey](RSAPrivateCrtKey.md) | The interface to an RSA private key, as defined in the [PKCS#1 v2.2](https://tools.ietf.org/rfc/rfc8017.txt) standard, using the*Chinese Remainder Theorem*(CRT) information values. |
| [RSAPrivateKey](RSAPrivateKey.md) | The interface to an RSA private key. |
| [RSAPublicKey](RSAPublicKey.md) | The interface to an RSA public key. |
| --- | --- |
| [XECKey](XECKey.md) | An interface for an elliptic curve public/private key as defined by RFC 7748. |
| [XECPrivateKey](XECPrivateKey.md) | An interface for an elliptic curve private key as defined by RFC 7748. |
| [XECPublicKey](XECPublicKey.md) | An interface for an elliptic curve public key as defined by RFC 7748. |
