# java.security.interfaces

## Interfaces

| [DSAKey](https://developer.android.com/reference/kotlin/java/security/interfaces/DSAKey) | The interface to a DSA public or private key. |
| --- | --- |
| [DSAKeyPairGenerator](https://developer.android.com/reference/kotlin/java/security/interfaces/DSAKeyPairGenerator) | An interface to an object capable of generating DSA key pairs. |
| [DSAParams](https://developer.android.com/reference/kotlin/java/security/interfaces/DSAParams) | Interface to a DSA-specific set of key parameters, which defines a DSA*key family*. |
| [DSAPrivateKey](https://developer.android.com/reference/kotlin/java/security/interfaces/DSAPrivateKey) | The standard interface to a DSA private key. |
| --- | --- |
| [DSAPublicKey](https://developer.android.com/reference/kotlin/java/security/interfaces/DSAPublicKey) | The interface to a DSA public key. |
| [ECKey](https://developer.android.com/reference/kotlin/java/security/interfaces/ECKey) | The interface to an elliptic curve (EC) key. |
| [ECPrivateKey](https://developer.android.com/reference/kotlin/java/security/interfaces/ECPrivateKey) | The interface to an elliptic curve (EC) private key. |
| --- | --- |
| [ECPublicKey](https://developer.android.com/reference/kotlin/java/security/interfaces/ECPublicKey) | The interface to an elliptic curve (EC) public key. |
| [EdECKey](https://developer.android.com/reference/kotlin/java/security/interfaces/EdECKey) | An interface for an elliptic curve public/private key as defined by [RFC 8032: Edwards-Curve Digital Signature Algorithm (EdDSA)](https://tools.ietf.org/html/rfc8032). |
| [EdECPrivateKey](https://developer.android.com/reference/kotlin/java/security/interfaces/EdECPrivateKey) | An interface for an elliptic curve private key as defined by [RFC 8032: Edwards-Curve Digital Signature Algorithm (EdDSA)](https://tools.ietf.org/html/rfc8032). |
| --- | --- |
| [EdECPublicKey](https://developer.android.com/reference/kotlin/java/security/interfaces/EdECPublicKey) | An interface for an elliptic curve public key as defined by [RFC 8032: Edwards-Curve Digital Signature Algorithm (EdDSA)](https://tools.ietf.org/html/rfc8032). |
| [RSAKey](https://developer.android.com/reference/kotlin/java/security/interfaces/RSAKey) | The interface to a public or private key in [PKCS#1 v2.2](https://tools.ietf.org/rfc/rfc8017.txt) standard, such as those for RSA, or RSASSA-PSS algorithms. |
| [RSAMultiPrimePrivateCrtKey](https://developer.android.com/reference/kotlin/java/security/interfaces/RSAMultiPrimePrivateCrtKey) | The interface to an RSA multi-prime private key, as defined in the [PKCS#1 v2.2](https://tools.ietf.org/rfc/rfc8017.txt) standard, using the*Chinese Remainder Theorem*(CRT) information values. |
| --- | --- |
| [RSAPrivateCrtKey](https://developer.android.com/reference/kotlin/java/security/interfaces/RSAPrivateCrtKey) | The interface to an RSA private key, as defined in the [PKCS#1 v2.2](https://tools.ietf.org/rfc/rfc8017.txt) standard, using the*Chinese Remainder Theorem*(CRT) information values. |
| [RSAPrivateKey](https://developer.android.com/reference/kotlin/java/security/interfaces/RSAPrivateKey) | The interface to an RSA private key. |

| [XECPublicKey](https://developer.android.com/reference/kotlin/java/security/interfaces/XECPublicKey) | An interface for an elliptic curve public key as defined by RFC 7748. |
