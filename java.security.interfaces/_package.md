# java.security.interfaces

## Interfaces

| [DSAKey](../java/security/interfaces/DSAKey.md) | The interface to a DSA public or private key. |
| --- | --- |
| [DSAKeyPairGenerator](../java/security/interfaces/DSAKeyPairGenerator.md) | An interface to an object capable of generating DSA key pairs. |
| [DSAParams](../java/security/interfaces/DSAParams.md) | Interface to a DSA-specific set of key parameters, which defines a DSA*key family*. |
| [DSAPrivateKey](../java/security/interfaces/DSAPrivateKey.md) | The standard interface to a DSA private key. |
| --- | --- |
| [DSAPublicKey](../java/security/interfaces/DSAPublicKey.md) | The interface to a DSA public key. |
| [ECKey](../java/security/interfaces/ECKey.md) | The interface to an elliptic curve (EC) key. |
| [ECPrivateKey](../java/security/interfaces/ECPrivateKey.md) | The interface to an elliptic curve (EC) private key. |
| --- | --- |
| [ECPublicKey](../java/security/interfaces/ECPublicKey.md) | The interface to an elliptic curve (EC) public key. |
| [EdECKey](../java/security/interfaces/EdECKey.md) | An interface for an elliptic curve public/private key as defined by [RFC 8032: Edwards-Curve Digital Signature Algorithm (EdDSA)](https://tools.ietf.org/html/rfc8032). |
| [EdECPrivateKey](../java/security/interfaces/EdECPrivateKey.md) | An interface for an elliptic curve private key as defined by [RFC 8032: Edwards-Curve Digital Signature Algorithm (EdDSA)](https://tools.ietf.org/html/rfc8032). |
| --- | --- |
| [EdECPublicKey](../java/security/interfaces/EdECPublicKey.md) | An interface for an elliptic curve public key as defined by [RFC 8032: Edwards-Curve Digital Signature Algorithm (EdDSA)](https://tools.ietf.org/html/rfc8032). |
| [RSAKey](../java/security/interfaces/RSAKey.md) | The interface to a public or private key in [PKCS#1 v2.2](https://tools.ietf.org/rfc/rfc8017.txt) standard, such as those for RSA, or RSASSA-PSS algorithms. |
| [RSAMultiPrimePrivateCrtKey](../java/security/interfaces/RSAMultiPrimePrivateCrtKey.md) | The interface to an RSA multi-prime private key, as defined in the [PKCS#1 v2.2](https://tools.ietf.org/rfc/rfc8017.txt) standard, using the*Chinese Remainder Theorem*(CRT) information values. |
| --- | --- |
| [RSAPrivateCrtKey](../java/security/interfaces/RSAPrivateCrtKey.md) | The interface to an RSA private key, as defined in the [PKCS#1 v2.2](https://tools.ietf.org/rfc/rfc8017.txt) standard, using the*Chinese Remainder Theorem*(CRT) information values. |
| [RSAPrivateKey](../java/security/interfaces/RSAPrivateKey.md) | The interface to an RSA private key. |
| [RSAPublicKey](../java/security/interfaces/RSAPublicKey.md) | The interface to an RSA public key. |
| --- | --- |
| [XECKey](../java/security/interfaces/XECKey.md) | An interface for an elliptic curve public/private key as defined by RFC 7748. |
| [XECPrivateKey](../java/security/interfaces/XECPrivateKey.md) | An interface for an elliptic curve private key as defined by RFC 7748. |
| [XECPublicKey](../java/security/interfaces/XECPublicKey.md) | An interface for an elliptic curve public key as defined by RFC 7748. |
| --- | --- |
