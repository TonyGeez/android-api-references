## Classes

| [AppUriAuthenticationPolicy](https://developer.android.com/reference/kotlin/android/security/AppUriAuthenticationPolicy) | The app-URI authentication policy is set by the credential management app. |
| --- | --- |
| [AttestedKeyPair](https://developer.android.com/reference/kotlin/android/security/AttestedKeyPair) | The `AttestedKeyPair` class contains a `KeyPair` instance of keys generated by Keystore and owned by KeyChain, as well as an attestation record for the key. |
| [ConfirmationCallback](https://developer.android.com/reference/kotlin/android/security/ConfirmationCallback) | Callback class used when signaling that a prompt is no longer being presented. |
| [ConfirmationPrompt](https://developer.android.com/reference/kotlin/android/security/ConfirmationPrompt) | Class used for displaying confirmation prompts. |
| --- | --- |
| [FileIntegrityManager](https://developer.android.com/reference/kotlin/android/security/FileIntegrityManager) | This class provides access to file integrity related operations. |
| [GrantedKeyInfo](https://developer.android.com/reference/kotlin/android/security/GrantedKeyInfo) | Information about a key pair granted to an application via KeyChain. |
| [KeyChain](https://developer.android.com/reference/kotlin/android/security/KeyChain) | The `KeyChain` class provides access to private keys and their corresponding certificate chains in credential storage. |
| --- | --- |
| [KeyChainManager](https://developer.android.com/reference/kotlin/android/security/KeyChainManager) | Manages KeyChain certificates and grants. |
| [KeyPairGeneratorSpec](https://developer.android.com/reference/kotlin/android/security/KeyPairGeneratorSpec) | This provides the required parameters needed for initializing the `KeyPairGenerator` that works with [Android KeyStore facility](https://developer.android.com/training/articles/keystore.html). |
| [KeyStoreParameter](https://developer.android.com/reference/kotlin/android/security/KeyStoreParameter) | This provides the optional parameters that can be specified for `KeyStore` entries that work with [Android KeyStore facility](https://developer.android.com/training/articles/keystore.html). |
| --- | --- |
| [NetworkSecurityPolicy](https://developer.android.com/reference/kotlin/android/security/NetworkSecurityPolicy) | Network security policy. |

## Exceptions

| [ConfirmationAlreadyPresentingException](https://developer.android.com/reference/kotlin/android/security/ConfirmationAlreadyPresentingException) | This exception is thrown when presenting a prompt fails because another prompt is already being presented. |
| --- | --- |
| [ConfirmationNotAvailableException](https://developer.android.com/reference/kotlin/android/security/ConfirmationNotAvailableException) | This exception is thrown when presenting a prompt fails because the environment lacks facilities for showing confirmations. |
| [KeyChainException](https://developer.android.com/reference/kotlin/android/security/KeyChainException) | Thrown on problems accessing the `https://developer.android.com/reference/kotlin/android/security/KeyChain`. |
| [KeyStoreException](https://developer.android.com/reference/kotlin/android/security/KeyStoreException) | Exception containing information about the failure at the Keystore / KeyMint layer while generating or using a key. |
