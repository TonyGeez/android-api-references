A class representing a Aware publish session. Created when `https://developer.android.com/reference/kotlin/android/net/wifi/aware/WifiAwareSession#publish(android.net.wifi.aware.PublishConfig,%20android.net.wifi.aware.DiscoverySessionCallback,%20android.os.Handler)` is called and a discovery session is created and returned in `https://developer.android.com/reference/kotlin/android/net/wifi/aware/DiscoverySessionCallback#onPublishStarted(android.net.wifi.aware.PublishDiscoverySession)`. See baseline functionality of all discovery sessions in `https://developer.android.com/reference/kotlin/android/net/wifi/aware/DiscoverySession`. This object allows updating an existing/running publish discovery session using `https://developer.android.com/reference/kotlin/android/net/wifi/aware/PublishDiscoverySession#updatePublish(android.net.wifi.aware.PublishConfig)`.

## Public methods

### acceptDataPathRequest

Added in [API level 37](https://developer.android.com/guide/topics/manifest/uses-sdk-element.html#ApiLevels)

```
open fun acceptDataPathRequest(
    peerHandle: PeerHandle, 
    request: AwareDataPathRequest
): Boolean
```

Accept a Wi-Fi Aware data path request to create a connection with the target peer. The Aware data path request should be done in the context of a discovery session - after a `https://developer.android.com/reference/kotlin/android/net/wifi/aware/DiscoverySessionCallback#onDataPathRequestReceived(android.net.wifi.aware.PeerHandle)` event is received. When the Aware data path setup succeeds, both side will receive `https://developer.android.com/reference/kotlin/android/net/wifi/aware/DiscoverySessionCallback#onDataPathConnected(android.net.wifi.aware.PeerHandle,%20android.net.wifi.aware.WifiAwareNetworkInfo)`. Otherwise `https://developer.android.com/reference/kotlin/android/net/wifi/aware/DiscoverySessionCallback#onDataPathRequestFailed(android.net.wifi.aware.PeerHandle,%20kotlin.Int)` will be called.

| Parameters ||
|---|---|
| `peerHandle` | [PeerHandle](PeerHandle.md): The peer's handle for the data path request. This value cannot be `null`. |
| `request` | [AwareDataPathRequest](../android/net/wifi/aware/AwareDataPathRequest.md): The data path request. This value cannot be `null`. |

### updatePublish

Added in [API level 26](https://developer.android.com/guide/topics/manifest/uses-sdk-element.html#ApiLevels)

```
open fun updatePublish(publishConfig: PublishConfig): Unit
```

Re-configure the currently active publish session. The `https://developer.android.com/reference/kotlin/android/net/wifi/aware/DiscoverySessionCallback` is not replaced - the same listener used at creation is still used. The results of the configuration are returned using `https://developer.android.com/reference/kotlin/android/net/wifi/aware/DiscoverySessionCallback`:

- `https://developer.android.com/reference/kotlin/android/net/wifi/aware/DiscoverySessionCallback#onSessionConfigUpdated()`: configuration update succeeded.
- `https://developer.android.com/reference/kotlin/android/net/wifi/aware/DiscoverySessionCallback#onSessionConfigFailed()`: configuration update failed. The publish discovery session is still running using its previous configuration (i.e. update failure does not terminate the session).

<br />

| Parameters ||
|---|---|
| `publishConfig` | [PublishConfig](PublishConfig.md): The new discovery publish session configuration (`https://developer.android.com/reference/kotlin/android/net/wifi/aware/PublishConfig`). This value cannot be `null`. |
