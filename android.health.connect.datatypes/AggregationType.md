Class to represent aggregation types in [Record](https://developer.android.com/reference/kotlin/android/health/connect/datatypes/Record) classes.

New objects of this class cannot be created.

Pre-created (defined in health [Record](https://developer.android.com/reference/kotlin/android/health/connect/datatypes/Record) types) objects of this class can be used to query and fetch aggregate results using aggregate APIs in [HealthConnectManager](https://developer.android.com/reference/kotlin/android/health/connect/HealthConnectManager.html#)
