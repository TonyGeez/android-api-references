# android.hardware.biometrics

## Interfaces

| [Authenticators](../android/hardware/biometrics/BiometricManager.Authenticators.md) | Types of authenticators, defined at a level of granularity supported by `https://developer.android.com/reference/kotlin/android/hardware/biometrics/BiometricManager` and `https://developer.android.com/reference/kotlin/android/hardware/biometrics/BiometricPrompt`. |
| --- | --- |
| [EmbeddedContentFactory](../android/hardware/biometrics/EmbeddedBiometricPrompt.EmbeddedContentFactory.md) | A factory that produces the custom embedded content view for the biometric prompt. |
| [PromptContentItem](../android/hardware/biometrics/PromptContentItem.md) | An item shown on `https://developer.android.com/reference/kotlin/android/hardware/biometrics/PromptContentView`. |
| [PromptContentView](../android/hardware/biometrics/PromptContentView.md) | Contains the information of the template of content view for Biometric Prompt. |
| --- | --- |

## Classes

| [BiometricManager](../android/hardware/biometrics/BiometricManager.md) | A class that contains biometric utilities. |
| --- | --- |
| [BiometricPrompt](../android/hardware/biometrics/BiometricPrompt.md) | A class that manages a system-provided biometric dialog. |
| [BiometricPromptStyleSpec](../android/hardware/biometrics/BiometricPromptStyleSpec.md) | A class that describes the visual styles of the embedded BiometricPrompt UI to allow client applications to maintain visual consistency. |
| [EmbeddedBiometricPrompt](../android/hardware/biometrics/EmbeddedBiometricPrompt.md) | The embedded version of `https://developer.android.com/reference/kotlin/android/hardware/biometrics/BiometricPrompt` that allows client apps to pass in content to display above the biometric prompt as a connected sheet. |
| --- | --- |
| [FallbackOption](../android/hardware/biometrics/FallbackOption.md) | Contains the information for a fallback option to be displayed within Biometric Prompt. |
| [PromptContentItemBulletedText](../android/hardware/biometrics/PromptContentItemBulletedText.md) | A list item with bulleted text shown on `https://developer.android.com/reference/kotlin/android/hardware/biometrics/PromptVerticalListContentView`. |
| [PromptContentItemPlainText](../android/hardware/biometrics/PromptContentItemPlainText.md) | A list item with plain text shown on `https://developer.android.com/reference/kotlin/android/hardware/biometrics/PromptVerticalListContentView`. |
| --- | --- |
| [PromptContentViewWithMoreOptionsButton](../android/hardware/biometrics/PromptContentViewWithMoreOptionsButton.md) | Contains the information of the template of content view with a more options button for Biometric Prompt. |
| [PromptVerticalListContentView](../android/hardware/biometrics/PromptVerticalListContentView.md) | Contains the information of the template of vertical list content view for Biometric Prompt. |
