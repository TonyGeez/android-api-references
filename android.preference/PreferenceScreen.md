| Use the [AndroidX](https://developer.android.com/jetpack/androidx.html) [Preference Library](https://developer.android.com/reference/androidx/preference/package-summary.html) for consistent behavior across all devices. For more information on using the AndroidX Preference Library see [Settings](https://developer.android.com/guide/topics/ui/settings.html).

Represents a top-level [Preference](https://developer.android.com/reference/kotlin/android/preference/Preference) that is the root of a Preference hierarchy. A [PreferenceActivity](https://developer.android.com/reference/kotlin/android/preference/PreferenceActivity) points to an instance of this class to show the preferences. To instantiate this class, use [PreferenceManager.createPreferenceScreen(Context)](https://developer.android.com/reference/kotlin/android/preference/PreferenceManager#createPreferenceScreen(android.content.Context)).

This class can appear in two places:
- When a [PreferenceActivity](https://developer.android.com/reference/kotlin/android/preference/PreferenceActivity) points to this, it is used as the root and is not shown (only the contained preferences are shown).
- When it appears inside another preference hierarchy, it is shown and serves as the gateway to another screen of preferences (either by showing another screen of preferences as a [Dialog](https://developer.android.com/reference/kotlin/android/app/Dialog.html#) or via a [Context.startActivity(android.content.Intent)](https://developer.android.com/reference/kotlin/android/content/Context.html#startActivity(android.content.Intent)) from the [Preference.getIntent()](https://developer.android.com/reference/kotlin/android/preference/Preference#getIntent())). The children of this [PreferenceScreen](https://developer.android.com/reference/kotlin/android/preference/PreferenceScreen#) are NOT shown in the screen that this [PreferenceScreen](https://developer.android.com/reference/kotlin/android/preference/PreferenceScreen#) is shown in. Instead, a separate screen will be shown when this preference is clicked.

<br />

Here's an example XML layout of a PreferenceScreen: 

```kotlin
<PreferenceScreen
        xmlns:android="http://schemas.android.com/apk/res/android"
        android:key="first_preferencescreen">
    <CheckBoxPreference
            android:key="wifi enabled"
            android:title="WiFi" />
    <PreferenceScreen
            android:key="second_preferencescreen"
            android:title="WiFi settings">
        <CheckBoxPreference
                android:key="prefer wifi"
                android:title="Prefer WiFi" />
        ... other preferences here ...
    </PreferenceScreen>
 </PreferenceScreen> 
```

In this example, the "first_preferencescreen" will be used as the root of the hierarchy and given to a [PreferenceActivity](https://developer.android.com/reference/kotlin/android/preference/PreferenceActivity). The first screen will show preferences "WiFi" (which can be used to quickly enable/disable WiFi) and "WiFi settings". The "WiFi settings" is the "second_preferencescreen" and when clicked will show another screen of preferences such as "Prefer WiFi" (and the other preferences that are children of the "second_preferencescreen" tag).

### getRootAdapter

Added in [API level 1](https://developer.android.com/guide/topics/manifest/uses-sdk-element.html#ApiLevels) 

```
fun getRootAdapter(): ListAdapter!
```

**Deprecated:** *Deprecated in Java.*

Returns an adapter that can be attached to a [PreferenceActivity](https://developer.android.com/reference/kotlin/android/preference/PreferenceActivity) or [PreferenceFragment](https://developer.android.com/reference/kotlin/android/preference/PreferenceFragment) to show the preferences contained in this [PreferenceScreen](https://developer.android.com/reference/kotlin/android/preference/PreferenceScreen#).

This [PreferenceScreen](https://developer.android.com/reference/kotlin/android/preference/PreferenceScreen#) will NOT appear in the returned adapter, instead it appears in the hierarchy above this [PreferenceScreen](https://developer.android.com/reference/kotlin/android/preference/PreferenceScreen#).

This adapter's [Adapter.getItem(int)](https://developer.android.com/reference/kotlin/android/widget/Adapter.html#getItem(kotlin.Int)) should always return a subclass of [Preference](https://developer.android.com/reference/kotlin/android/preference/Preference).

| Return ||
|---|---|
| [ListAdapter](https://developer.android.com/reference/kotlin/android/widget/ListAdapter.html#)! | An adapter that provides the [Preference](https://developer.android.com/reference/kotlin/android/preference/Preference) contained in this [PreferenceScreen](https://developer.android.com/reference/kotlin/android/preference/PreferenceScreen#). |
