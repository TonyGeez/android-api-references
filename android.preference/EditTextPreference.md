A [Preference](https://developer.android.com/reference/kotlin/android/preference/Preference) that allows for string input.

It is a subclass of [DialogPreference](https://developer.android.com/reference/kotlin/android/preference/DialogPreference) and shows the [EditText](https://developer.android.com/reference/kotlin/android/widget/EditText.html#) in a dialog. This [EditText](https://developer.android.com/reference/kotlin/android/widget/EditText.html#) can be modified either programmatically via [getEditText()](https://developer.android.com/reference/kotlin/android/preference/EditTextPreference#getEditText()), or through XML by setting any EditText attributes on the EditTextPreference.

This preference will store a string into the SharedPreferences.

See [EditText Attributes](https://developer.android.com/reference/kotlin/android/R.styleable.html#EditText:kotlin.IntArray).
