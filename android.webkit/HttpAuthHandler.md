Represents a request for HTTP authentication. Instances of this class are created by the WebView and passed to [WebViewClient.onReceivedHttpAuthRequest](https://developer.android.com/reference/kotlin/android/webkit/WebViewClient#onReceivedHttpAuthRequest(android.webkit.WebView,%20android.webkit.HttpAuthHandler,%20kotlin.String,%20kotlin.String)). The host application must call either [proceed](https://developer.android.com/reference/kotlin/android/webkit/HttpAuthHandler#proceed(kotlin.String,%20kotlin.String))or [cancel](https://developer.android.com/reference/kotlin/android/webkit/HttpAuthHandler#cancel())to set the WebView's response to the request.

## Public methods

### cancel

Added in [API level 1](https://developer.android.com/guide/topics/manifest/uses-sdk-element.html#ApiLevels) 

```
open fun cancel(): Unit
```

Instructs the WebView to cancel the authentication request.

**Note:**The host application must call this method on the host application's UI Thread. 

### proceed

Added in [API level 1](https://developer.android.com/guide/topics/manifest/uses-sdk-element.html#ApiLevels) 

```
open fun proceed(
    username: String!, 
    password: String!
): Unit
```

Instructs the WebView to proceed with the authentication with the given credentials. Credentials for use with this method can be retrieved from the WebView's store using [WebView.getHttpAuthUsernamePassword](https://developer.android.com/reference/kotlin/android/webkit/WebView#getHttpAuthUsernamePassword(kotlin.String,%20kotlin.String)).

**Note:**The host application must call this method on the host application's UI Thread. 

### useHttpAuthUsernamePassword

Added in [API level 1](https://developer.android.com/guide/topics/manifest/uses-sdk-element.html#ApiLevels) 

```
open fun useHttpAuthUsernamePassword(): Boolean
```

Gets whether the credentials stored for the current host (i.e. the host for which [WebViewClient.onReceivedHttpAuthRequest](https://developer.android.com/reference/kotlin/android/webkit/WebViewClient#onReceivedHttpAuthRequest(android.webkit.WebView,%20android.webkit.HttpAuthHandler,%20kotlin.String,%20kotlin.String))was called) are suitable for use. Credentials are not suitable if they have previously been rejected by the server for the current request.

**Note:**The host application must call this method on the host application's UI Thread.

| [Boolean](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin/-boolean/index.html) | whether the credentials are suitable for use |
