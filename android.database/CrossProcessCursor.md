A cross process cursor is an extension of a `https://developer.android.com/reference/kotlin/android/database/Cursor` that also supports usage from remote processes.

The contents of a cross process cursor are marshalled to the remote process by filling `https://developer.android.com/reference/kotlin/android/database/CursorWindow` objects using `https://developer.android.com/reference/kotlin/android/database/CrossProcessCursor#fillWindow(kotlin.Int,%20android.database.CursorWindow)`. As an optimization, the cursor can provide a pre-filled window to use via `https://developer.android.com/reference/kotlin/android/database/CrossProcessCursor#getWindow()` thereby obviating the need to copy the data to yet another cursor window.

## Public methods

### fillWindow

Added in [API level 1](https://developer.android.com/guide/topics/manifest/uses-sdk-element.html#ApiLevels)

```
abstract fun fillWindow(
    position: Int, 
    window: CursorWindow!
): Unit
```

Copies cursor data into the window.

Clears the window and fills it with data beginning at the requested row position until all of the data in the cursor is exhausted or the window runs out of space.

The filled window uses the same row indices as the original cursor. For example, if you fill a window starting from row 5 from the cursor, you can query the contents of row 5 from the window just by asking it for row 5 because there is a direct correspondence between the row indices used by the cursor and the window.

The current position of the cursor, as returned by `https://developer.android.com/reference/kotlin/android/database/Cursor#getPosition()`, is not changed by this method.

| Parameters ||
|---|---|
| `position` | [Int](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin/-int/index.html): The zero-based index of the first row to copy into the window. |
| `window` | [CursorWindow](../android/database/CursorWindow.md)!: The window to fill. |

### getWindow

Added in [API level 1](https://developer.android.com/guide/topics/manifest/uses-sdk-element.html#ApiLevels)

```
abstract fun getWindow(): CursorWindow!
```

Returns a pre-filled window that contains the data within this cursor.

In particular, the window contains the row indicated by `https://developer.android.com/reference/kotlin/android/database/Cursor#getPosition()`. The window's contents are automatically scrolled whenever the current row moved outside the range covered by the window.

| Return ||
|---|---|
| `https://developer.android.com/reference/kotlin/android/database/CursorWindow!` | The pre-filled window, or null if none. |

### onMove

Added in [API level 1](https://developer.android.com/guide/topics/manifest/uses-sdk-element.html#ApiLevels)

```
abstract fun onMove(
    oldPosition: Int, 
    newPosition: Int
): Boolean
```

This function is called every time the cursor is successfully scrolled to a new position, giving the subclass a chance to update any state it may have. If it returns false the move function will also do so and the cursor will scroll to the beforeFirst position.

This function should be called by methods such as `https://developer.android.com/reference/kotlin/android/database/Cursor#moveToPosition(kotlin.Int)`, so it will typically not be called from outside of the cursor class itself.

| Return ||
|---|---|
| `https://kotlinlang.org/api/latest/jvm/stdlib/kotlin/-boolean/index.html` | True if the move is successful, false otherwise. |
