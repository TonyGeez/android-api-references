Cursor wrapper that implements [CrossProcessCursor](https://developer.android.com/reference/kotlin/android/database/CrossProcessCursor).

If the wrapped cursor implements [CrossProcessCursor](https://developer.android.com/reference/kotlin/android/database/CrossProcessCursor), then the wrapper delegates [fillWindow](https://developer.android.com/reference/kotlin/android/database/CrossProcessCursorWrapper#fillWindow(kotlin.Int,%20android.database.CursorWindow)), [getWindow()](https://developer.android.com/reference/kotlin/android/database/CrossProcessCursorWrapper#getWindow())and [onMove](https://developer.android.com/reference/kotlin/android/database/CrossProcessCursorWrapper#onMove(kotlin.Int,%20kotlin.Int))to it. Otherwise, the wrapper provides default implementations of these methods that traverse the contents of the cursor similar to [AbstractCursor.fillWindow](https://developer.android.com/reference/kotlin/android/database/AbstractCursor#fillWindow(kotlin.Int,%20android.database.CursorWindow)).

This wrapper can be used to adapt an ordinary [Cursor](https://developer.android.com/reference/kotlin/android/database/Cursor) into a [CrossProcessCursor](https://developer.android.com/reference/kotlin/android/database/CrossProcessCursor).
