## Public methods

### getTypeParameters

Added in [API level 1](https://developer.android.com/guide/topics/manifest/uses-sdk-element.html#ApiLevels) 

```
abstract fun getTypeParameters(): Array<TypeVariable<*>!>
```

Returns an array of`TypeVariable`objects that represent the type variables declared by the generic declaration represented by this`GenericDeclaration`object, in declaration order. Returns an array of length 0 if the underlying generic declaration declares no type variables.

| Return ||
|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------|
| [Array](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin/-array/index.html)< [TypeVariable](https://developer.android.com/reference/kotlin/java/lang/reflect/TypeVariable)<*>!> | an array of`TypeVariable`objects that represent the type variables declared by this generic declaration |
