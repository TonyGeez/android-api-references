A channel that can read and write bytes. This interface simply unifies [ReadableByteChannel](https://developer.android.com/reference/kotlin/java/nio/channels/ReadableByteChannel) and [WritableByteChannel](https://developer.android.com/reference/kotlin/java/nio/channels/WritableByteChannel); it does not specify any new operations.
