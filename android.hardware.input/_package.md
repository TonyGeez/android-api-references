# android.hardware.input

## Interfaces

| [InputDeviceListener](https://developer.android.com/reference/kotlin/android/hardware/input/InputManager.InputDeviceListener) | Listens for changes in input devices. |

## Classes

| [AppCustomizationAction](https://developer.android.com/reference/kotlin/android/hardware/input/AppCustomizationAction) | Represents an action that launches or sends an intent to a specific application component in response to a peripheral input customization trigger. |
| [ButtonCustomizationTrigger](https://developer.android.com/reference/kotlin/android/hardware/input/ButtonCustomizationTrigger) | Represents a trigger based on a physical button press on a peripheral (e.g., a mouse). |
| [CustomizationAction](https://developer.android.com/reference/kotlin/android/hardware/input/CustomizationAction) | Represents an action that can be associated with a peripheral customization trigger. |
| [CustomizationTrigger](https://developer.android.com/reference/kotlin/android/hardware/input/CustomizationTrigger) | Represents a trigger that initiates a peripheral customization action. |
| [HostUsiVersion](https://developer.android.com/reference/kotlin/android/hardware/input/HostUsiVersion) | Provides information about the supported Universal Stylus Initiative (USI) version of the host device. |
| [InputManager](https://developer.android.com/reference/kotlin/android/hardware/input/InputManager) | Provides information about input devices and available key layouts. |
| [KeyCustomizationTrigger](https://developer.android.com/reference/kotlin/android/hardware/input/KeyCustomizationTrigger) | Represents a trigger based on a physical key press on a peripheral. |
| [SimpleCustomizationAction](https://developer.android.com/reference/kotlin/android/hardware/input/SimpleCustomizationAction) | Represents predefined simple actions, such as Volume up/down, Screenshot, etc. |
| [UriCustomizationAction](https://developer.android.com/reference/kotlin/android/hardware/input/UriCustomizationAction) | Represents an action that requires an accompanying URI to execute. |
