# android.util.function

## Interfaces

| [IntObjFunction](https://developer.android.com/reference/kotlin/android/util/function/IntObjFunction) | Represents a function that accepts an `int`-valued argument and an object-valued argument, and produces a result. |
| [LongObjFunction](https://developer.android.com/reference/kotlin/android/util/function/LongObjFunction) | Represents a function that accepts a `long`-valued argument and an object-valued argument, and produces a result. |
