Provides a simple [ClassLoader](../java.lang/ClassLoader.md) implementation that operates on a list of files and directories in the local file system, but does not attempt to load classes from the network. Android uses this class for its system class loader and for its application class loader(s).

### PathClassLoader

Added in [API level 1](https://developer.android.com/guide/topics/manifest/uses-sdk-element.html#ApiLevels) 

```
PathClassLoader(
    dexPath: String!, 
    librarySearchPath: String!, 
    parent: ClassLoader!)
```

Creates a`PathClassLoader`that operates on two given lists of files and directories. The entries of the first list should be one of the following:

- JAR/ZIP/APK files, possibly containing a "classes.dex" file as well as arbitrary resources.
- Raw ".dex" files (not inside a zip file).

The entries of the second list should be directories containing native library files.

| `librarySearchPath` | [String](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin/-string/index.html)!:the list of directories containing native libraries, delimited by`File.pathSeparator`; may be`null` |
