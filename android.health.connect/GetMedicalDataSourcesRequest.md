A create request for android.health.connect.HealthConnectManager#getMedicalDataSources.

If no [package names](https://developer.android.com/reference/kotlin/android/health/connect/GetMedicalDataSourcesRequest#getPackageNames())are set, requests all [MedicalDataSource](https://developer.android.com/reference/kotlin/android/health/connect/datatypes/MedicalDataSource) s from all packages. Otherwise the request is limited to the requested package names.
