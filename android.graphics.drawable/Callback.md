Implement this interface if you want to create an animated drawable that extends [Drawable](https://developer.android.com/reference/kotlin/android/graphics/drawable/Drawable). Upon retrieving a drawable, use [Drawable.setCallback(android.graphics.drawable.Drawable.Callback)](https://developer.android.com/reference/kotlin/android/graphics/drawable/Drawable#setCallback(android.graphics.drawable.Drawable.Callback))to supply your implementation of the interface to the drawable; it uses this interface to schedule and execute animation changes.

## Public methods

### invalidateDrawable

Added in [API level 1](https://developer.android.com/guide/topics/manifest/uses-sdk-element.html#ApiLevels) 

```
abstract fun invalidateDrawable(who: Drawable): Unit
```

Called when the drawable needs to be redrawn. A view at this point should invalidate itself (or at least the part of itself where the drawable appears).

| Parameters ||
|-------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `who` | [Drawable](https://developer.android.com/reference/kotlin/android/graphics/drawable/Drawable):The drawable that is requesting the update. This value cannot be`null`. |

### scheduleDrawable

Added in [API level 1](https://developer.android.com/guide/topics/manifest/uses-sdk-element.html#ApiLevels) 

```
abstract fun scheduleDrawable(
    who: Drawable, 
    what: Runnable, 
    when: Long
): Unit
```

A Drawable can call this to schedule the next frame of its animation. An implementation can generally simply call [android.os.Handler#postAtTime(Runnable, Object, long)](https://developer.android.com/reference/kotlin/android/os/Handler.html#postAtTime(java.lang.Runnable,%20kotlin.Any,%20kotlin.Long))with the parameters (what, who, when) to perform the scheduling.

| Parameters ||
|--------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `who` | [Drawable](https://developer.android.com/reference/kotlin/android/graphics/drawable/Drawable):The drawable being scheduled. This value cannot be`null`. |
| `what` | [Runnable](https://developer.android.com/reference/kotlin/java/lang/Runnable.html#):The action to execute. This value cannot be`null`. |
| `when` | [Long](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin/-long/index.html):The time (in milliseconds) to run. The timebase is [android.os.SystemClock#uptimeMillis](https://developer.android.com/reference/kotlin/android/os/SystemClock.html#uptimeMillis()) |

### unscheduleDrawable

Added in [API level 1](https://developer.android.com/guide/topics/manifest/uses-sdk-element.html#ApiLevels) 

```
abstract fun unscheduleDrawable(
    who: Drawable, 
    what: Runnable
): Unit
```

A Drawable can call this to unschedule an action previously scheduled with [scheduleDrawable](https://developer.android.com/reference/kotlin/android/graphics/drawable/Drawable.Callback#scheduleDrawable(android.graphics.drawable.Drawable,%20java.lang.Runnable,%20kotlin.Long)). An implementation can generally simply call [android.os.Handler#removeCallbacks(Runnable, Object)](https://developer.android.com/reference/kotlin/android/os/Handler.html#removeCallbacks(java.lang.Runnable,%20kotlin.Any))with the parameters (what, who) to unschedule the drawable.

| Parameters ||
|--------|-----------------------------------------------------------------------------------------------------------------------------------------------------------|
| `who` | [Drawable](https://developer.android.com/reference/kotlin/android/graphics/drawable/Drawable):The drawable being unscheduled. This value cannot be`null`. |
| `what` | [Runnable](https://developer.android.com/reference/kotlin/java/lang/Runnable.html#):The action being unscheduled. This value cannot be`null`. |
