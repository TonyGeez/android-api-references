## Interfaces

| [HpkeSpi](https://developer.android.com/reference/kotlin/android/crypto/hpke/HpkeSpi) | Service Provider Interface for HPKE client API classes to communicate with implementations of HPKE as described in RFC 9180. |

| [Hpke](https://developer.android.com/reference/kotlin/android/crypto/hpke/Hpke) | Provides access to implementations of HPKE hybrid cryptography as per RFC 9180. |

| [KemParameterSpec](https://developer.android.com/reference/kotlin/android/crypto/hpke/KemParameterSpec) | Specifies algorithm parameters for the KEM component of an HPKE suite which are determined by standard names as per RFC 9180. |
