The XML parsing interface returned for an XML resource. This is a standard [XmlPullParser](../org.xmlpull.v1/XmlPullParser.md) interface but also extends [AttributeSet](../android.util/AttributeSet.md) and adds an additional [close()](XmlResourceParser.md)) method for the client to indicate when it is done reading the resource.
