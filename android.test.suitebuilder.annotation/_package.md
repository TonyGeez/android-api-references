| [MediumTest](https://developer.android.com/reference/kotlin/android/test/suitebuilder/annotation/MediumTest) | Marks a test that should run as part of the medium tests. |
| [SmallTest](https://developer.android.com/reference/kotlin/android/test/suitebuilder/annotation/SmallTest) | Marks a test that should run as part of the small tests. |
| [Smoke](https://developer.android.com/reference/kotlin/android/test/suitebuilder/annotation/Smoke) | Marks a test that should run as part of the smoke tests. |
| [Suppress](https://developer.android.com/reference/kotlin/android/test/suitebuilder/annotation/Suppress) | Use this annotation on test classes or test methods that should not be included in a test suite. |
