An extension of SpinnerAdapter that is capable of inflating drop-down views against a different theme than normal views.

Classes that implement this interface should use the theme provided to [setDropDownViewTheme(android.content.res.Resources.Theme)](https://developer.android.com/reference/kotlin/android/widget/ThemedSpinnerAdapter#setDropDownViewTheme(android.content.res.Resources.Theme))when creating views in [SpinnerAdapter.getDropDownView(int, View, ViewGroup)](https://developer.android.com/reference/kotlin/android/widget/SpinnerAdapter#getDropDownView(kotlin.Int,%20android.view.View,%20android.view.ViewGroup)).
