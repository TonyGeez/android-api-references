Validator that returns `true` if the number created by concatenating all given fields pass a Luhn algorithm checksum. All non-digits are ignored.

See `https://developer.android.com/reference/kotlin/android/service/autofill/SaveInfo.Builder#setValidator(android.service.autofill.Validator)` for examples.
