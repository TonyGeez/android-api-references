## Public methods

### sendAccessibilityEvent

Added in [API level 4](https://developer.android.com/guide/topics/manifest/uses-sdk-element.html#ApiLevels) 

```
abstract fun sendAccessibilityEvent(eventType: Int): Unit
```

Handles the request for sending an [AccessibilityEvent](AccessibilityEvent.md) given the event type. The method must first check if accessibility is on via calling [AccessibilityManager.isEnabled()](AccessibilityManager.md)), obtain an [AccessibilityEvent](AccessibilityEvent.md) from the event pool through calling [AccessibilityEvent.obtain(int)](AccessibilityEvent.md)), populate the event, and send it for dispatch via calling [AccessibilityManager.sendAccessibilityEvent(AccessibilityEvent)](AccessibilityManager.md)).

| Parameters ||
|-------------|--------------------------------------------------------------------------------------------|
| `eventType` | [Int](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin/-int/index.html):The event type. |

### sendAccessibilityEventUnchecked

Added in [API level 4](https://developer.android.com/guide/topics/manifest/uses-sdk-element.html#ApiLevels) 

```
abstract fun sendAccessibilityEventUnchecked(event: AccessibilityEvent!): Unit
```

Handles the request for sending an [AccessibilityEvent](AccessibilityEvent.md). The method does not guarantee to check if accessibility is on before sending the event for dispatch. It is responsibility of the caller to do the check via calling [AccessibilityManager.isEnabled()](AccessibilityManager.md)).

| Parameters ||
|---------|--------------------------------------------------------------------------------------------------------------------------------|
| `event` | [AccessibilityEvent](AccessibilityEvent.md)!:The event. |
