## Public methods

### sendAccessibilityEvent

Added in [API level 4](https://developer.android.com/guide/topics/manifest/uses-sdk-element.html#ApiLevels) 

```
abstract fun sendAccessibilityEvent(eventType: Int): Unit
```

Handles the request for sending an [AccessibilityEvent](https://developer.android.com/reference/kotlin/android/view/accessibility/AccessibilityEvent) given the event type. The method must first check if accessibility is on via calling [AccessibilityManager.isEnabled()](https://developer.android.com/reference/kotlin/android/view/accessibility/AccessibilityManager#isEnabled()), obtain an [AccessibilityEvent](https://developer.android.com/reference/kotlin/android/view/accessibility/AccessibilityEvent) from the event pool through calling [AccessibilityEvent.obtain(int)](https://developer.android.com/reference/kotlin/android/view/accessibility/AccessibilityEvent#obtain(kotlin.Int)), populate the event, and send it for dispatch via calling [AccessibilityManager.sendAccessibilityEvent(AccessibilityEvent)](https://developer.android.com/reference/kotlin/android/view/accessibility/AccessibilityManager#sendAccessibilityEvent(android.view.accessibility.AccessibilityEvent)).

| Parameters ||
|-------------|--------------------------------------------------------------------------------------------|
| `eventType` | [Int](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin/-int/index.html):The event type. |

### sendAccessibilityEventUnchecked

Added in [API level 4](https://developer.android.com/guide/topics/manifest/uses-sdk-element.html#ApiLevels) 

```
abstract fun sendAccessibilityEventUnchecked(event: AccessibilityEvent!): Unit
```

Handles the request for sending an [AccessibilityEvent](https://developer.android.com/reference/kotlin/android/view/accessibility/AccessibilityEvent). The method does not guarantee to check if accessibility is on before sending the event for dispatch. It is responsibility of the caller to do the check via calling [AccessibilityManager.isEnabled()](https://developer.android.com/reference/kotlin/android/view/accessibility/AccessibilityManager#isEnabled()).

|---------|--------------------------------------------------------------------------------------------------------------------------------|
| `event` | [AccessibilityEvent](https://developer.android.com/reference/kotlin/android/view/accessibility/AccessibilityEvent)!:The event. |
