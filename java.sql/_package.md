# java.sql

## Interfaces

| [Array](https://developer.android.com/reference/kotlin/java/sql/Array) | The mapping in the Java programming language for the SQL type`ARRAY`. |
| [Blob](https://developer.android.com/reference/kotlin/java/sql/Blob) | The representation (mapping) in the JavaTM programming language of an SQL`BLOB`value. |
| [CallableStatement](https://developer.android.com/reference/kotlin/java/sql/CallableStatement) | The interface used to execute SQL stored procedures. |
| [Clob](https://developer.android.com/reference/kotlin/java/sql/Clob) | The mapping in the JavaTM programming language for the SQL`CLOB`type. |
| [Connection](https://developer.android.com/reference/kotlin/java/sql/Connection) | A connection (session) with a specific database. |
| [DatabaseMetaData](https://developer.android.com/reference/kotlin/java/sql/DatabaseMetaData) | Comprehensive information about the database as a whole. |
| [Driver](https://developer.android.com/reference/kotlin/java/sql/Driver) | The interface that every driver class must implement. |
| [NClob](https://developer.android.com/reference/kotlin/java/sql/NClob) | The mapping in the JavaTM programming language for the SQL`NCLOB`type. |
| [ParameterMetaData](https://developer.android.com/reference/kotlin/java/sql/ParameterMetaData) | An object that can be used to get information about the types and properties for each parameter marker in a`PreparedStatement`object. |
| [PreparedStatement](https://developer.android.com/reference/kotlin/java/sql/PreparedStatement) | An object that represents a precompiled SQL statement. |
| [Ref](https://developer.android.com/reference/kotlin/java/sql/Ref) | The mapping in the Java programming language of an SQL`REF`value, which is a reference to an SQL structured type value in the database. |
| [ResultSet](https://developer.android.com/reference/kotlin/java/sql/ResultSet) | A table of data representing a database result set, which is usually generated by executing a statement that queries the database. |
| [ResultSetMetaData](https://developer.android.com/reference/kotlin/java/sql/ResultSetMetaData) | An object that can be used to get information about the types and properties of the columns in a`ResultSet`object. |
| [RowId](https://developer.android.com/reference/kotlin/java/sql/RowId) | The representation (mapping) in the Java programming language of an SQL ROWID value. |
| [Savepoint](https://developer.android.com/reference/kotlin/java/sql/Savepoint) | The representation of a savepoint, which is a point within the current transaction that can be referenced from the`Connection.rollback`method. |
| [SQLData](https://developer.android.com/reference/kotlin/java/sql/SQLData) | The interface used for the custom mapping of an SQL user-defined type (UDT) to a class in the Java programming language. |
| [SQLInput](https://developer.android.com/reference/kotlin/java/sql/SQLInput) | An input stream that contains a stream of values representing an instance of an SQL structured type or an SQL distinct type. |
| [SQLOutput](https://developer.android.com/reference/kotlin/java/sql/SQLOutput) | The output stream for writing the attributes of a user-defined type back to the database. |
| [SQLXML](https://developer.android.com/reference/kotlin/java/sql/SQLXML) | The mapping in the JavaTM programming language for the SQL XML type. |
| [Statement](https://developer.android.com/reference/kotlin/java/sql/Statement) | The object used for executing a static SQL statement and returning the results it produces. |
| [Struct](https://developer.android.com/reference/kotlin/java/sql/Struct) | The standard mapping in the Java programming language for an SQL structured type. |
| [Wrapper](https://developer.android.com/reference/kotlin/java/sql/Wrapper) | Interface for JDBC classes which provide the ability to retrieve the delegate instance when the instance in question is in fact a proxy class. |

| [SQLIntegrityConstraintViolationException](https://developer.android.com/reference/kotlin/java/sql/SQLIntegrityConstraintViolationException) | The subclass of [SQLException](https://developer.android.com/reference/kotlin/java/sql/SQLException) thrown when the SQLState class value is '*23*', or under vendor-specified conditions. |
| [SQLInvalidAuthorizationSpecException](https://developer.android.com/reference/kotlin/java/sql/SQLInvalidAuthorizationSpecException) | The subclass of [SQLException](https://developer.android.com/reference/kotlin/java/sql/SQLException) thrown when the SQLState class value is '*28*', or under vendor-specified conditions. |
| [SQLNonTransientConnectionException](https://developer.android.com/reference/kotlin/java/sql/SQLNonTransientConnectionException) | The subclass of [SQLException](https://developer.android.com/reference/kotlin/java/sql/SQLException) thrown for the SQLState class value '*08*', or under vendor-specified conditions. |
| [SQLNonTransientException](https://developer.android.com/reference/kotlin/java/sql/SQLNonTransientException) | The subclass of [SQLException](https://developer.android.com/reference/kotlin/java/sql/SQLException) thrown when an instance where a retry of the same operation would fail unless the cause of the`SQLException`is corrected. |

| [SQLSyntaxErrorException](https://developer.android.com/reference/kotlin/java/sql/SQLSyntaxErrorException) | The subclass of [SQLException](https://developer.android.com/reference/kotlin/java/sql/SQLException) thrown when the SQLState class value is '*42*', or under vendor-specified conditions. |

| [SQLTransactionRollbackException](https://developer.android.com/reference/kotlin/java/sql/SQLTransactionRollbackException) | The subclass of [SQLException](https://developer.android.com/reference/kotlin/java/sql/SQLException) thrown when the SQLState class value is '*40*', or under vendor-specified conditions. |
| [SQLTransientConnectionException](https://developer.android.com/reference/kotlin/java/sql/SQLTransientConnectionException) | The subclass of [SQLException](https://developer.android.com/reference/kotlin/java/sql/SQLException) for the SQLState class value '*08*', or under vendor-specified conditions. |
| [SQLTransientException](https://developer.android.com/reference/kotlin/java/sql/SQLTransientException) | The subclass of [SQLException](https://developer.android.com/reference/kotlin/java/sql/SQLException) is thrown in situations where a previoulsy failed operation might be able to succeed when the operation is retried without any intervention by application-level functionality. |
| [SQLWarning](https://developer.android.com/reference/kotlin/java/sql/SQLWarning) | An exception that provides information on database access warnings. |
