This class contains the list of alpha compositing and blending modes that can be passed to [PorterDuffXfermode](https://developer.android.com/reference/kotlin/android/graphics/PorterDuffXfermode), a specialized implementation of [Paint](https://developer.android.com/reference/kotlin/android/graphics/Paint)'s [transfer mode](https://developer.android.com/reference/kotlin/android/graphics/Paint#setXfermode(android.graphics.Xfermode)). All the available modes can be found in the [Mode](https://developer.android.com/reference/kotlin/android/graphics/PorterDuff.Mode) enum.
Consider using [BlendMode](https://developer.android.com/reference/kotlin/android/graphics/BlendMode) instead as it provides a wider variety of tinting options
