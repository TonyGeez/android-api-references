This transition tracks changes to the visibility of target views in the start and end scenes and fades views in or out when they become visible or non-visible. Visibility is determined by both the `https://developer.android.com/reference/kotlin/android/view/View.html#setVisibility(kotlin.Int)` state of the view as well as whether it is parented in the current view hierarchy.

The ability of this transition to fade out a particular view, and the way that that fading operation takes place, is based on the situation of the view in the view hierarchy. For example, if a view was simply removed from its parent, then the view will be added into a `https://developer.android.com/reference/kotlin/android/view/ViewGroupOverlay.html#` while fading. If a visible view is changed to be `https://developer.android.com/reference/kotlin/android/view/View.html#GONE:kotlin.Int` or `https://developer.android.com/reference/kotlin/android/view/View.html#INVISIBLE:kotlin.Int`, then the visibility will be changed to `https://developer.android.com/reference/kotlin/android/view/View.html#VISIBLE:kotlin.Int` for the duration of the animation. However, if a view is in a hierarchy which is also altering its visibility, the situation can be more complicated. In general, if a view that is no longer in the hierarchy in the end scene still has a parent (so its parent hierarchy was removed, but it was not removed from its parent), then it will be left alone to avoid side-effects from improperly removing it from its parent. The only exception to this is if the previous `https://developer.android.com/reference/kotlin/android/transition/Scene` was `https://developer.android.com/reference/kotlin/android/transition/Scene#getSceneForLayout(android.view.ViewGroup,%20kotlin.Int,%20android.content.Context)`, then it is considered safe to un-parent the starting scene view in order to fade it out.

A Fade transition can be described in a resource file by using the tag `fade`, along with the standard attributes of `https://developer.android.com/reference/kotlin/android/R.styleable.html#Fade:kotlin.IntArray` and `https://developer.android.com/reference/kotlin/android/R.styleable.html#Transition:kotlin.IntArray`.
